## 项目简介

Vision Skill Forge 是一个面向图片和视频的视觉技能构建器。用户只需描述要识别的目标、属性、关系、区域、数量、时序行为或业务事件，系统就会把自然语言意图转换为可审核、可编辑、可校验、可执行的类型化工作流，并输出带可视化证据的结果。

项目采用“大模型编排 + 确定性编译”的方式：大模型只从已注册的业务能力与执行原子中选择和组合；固定代码负责校验方案、生成运行图、执行视觉推理、绑定实体证据并形成可解释的业务结果。

## 为什么需要 Vision Skill Forge？

| 常规视觉演示 | Vision Skill Forge |
| --- | --- |
| 检测逻辑隐藏在代码中 | 生成的工作流完整可见、可编辑 |
| 一条提示词直接得到黑盒结果 | 保留标注框、证据、判断过程和执行轨迹 |
| 复杂任务需要逐场景编写代码 | 可组合目标、属性、区域、关系、数量、逻辑和事件 |
| 相似模型查询被重复执行 | 同一推理图片／帧的兼容类别合并为一次 Grounding 请求 |
| 直接把模型输出当成业务结论 | 视觉证据与业务判断明确分离 |

## 核心能力

- **一句话创建技能**：将自然语言需求转换为完整视觉技能。
- **类型化视觉工作流**：只编排已注册、带版本、输入输出及参数明确的执行算子。
- **可编辑业务逻辑**：可审核和调整分支、AND / OR / NOT、阈值、区域、关系、事件及触发策略。
- **单次多类别推理**：兼容类别合并检测，后续统一完成证据归属和实例去重。
- **图片与视频通用**：共享语义意图，按媒体生成不同的执行图。
- **结果可解释**：可查看标注框、中间证据、节点执行轨迹和最终业务结果。
- **P01–P13 预置演示**：覆盖交通、安全、设施管理和基础设施巡检场景。

## 工作原理

```text
一句自然语言需求
        ↓
规范化语义 IR
        ↓
业务能力 + 执行原子
        ↓
确定性类型编译器
        ↓
可编辑 SkillPackage
        ↓
视觉推理 → 证据归属 → 逻辑与事件
        ↓
带标注、可解释的业务结果
```

大模型只进行受约束的方案编排，不生成运行时代码，也不能虚构未注册的算子。

## 快速启动

### 前置条件

- 已安装 `requirements.txt` 中依赖的 Python 环境
- 已在 `.env` 中配置 Planner API，可参考 `.env.example`
- Rex-Omni OpenAI-compatible 服务可通过 `http://127.0.0.1:8000/v1` 访问
- 当前预置默认素材及媒体相关测试还需要原本地 `imgs/`、`data/acceptance_media/`；这两个目录未入 Git，已入库的 `data/demo_media/` 不能覆盖全部当前默认素材。

真实 API 密钥只应保存在本地 `.env` 中，不要提交到仓库。

### 安装与运行

```powershell
git clone https://github.com/yyhhee/vision-skill-forge.git
cd vision-skill-forge
conda env create -f environment.yml
conda activate vision-skill
pip install -r requirements.txt
$env:VISION_SKILL_PORT = "6131"
python app_v2.py
```

浏览器访问 [http://127.0.0.1:6131](http://127.0.0.1:6131)。
已有 `vision-skill` 环境时，跳过创建环境一步。上面的环境变量显式选择 6131；不设置 `VISION_SKILL_PORT` 时，`app_v2.py` 默认使用 6122。
启动前需恢复上述本地媒体。仅克隆代码时，可能在初始化默认素材目录时失败（如缺少 P01 图片）；本回退点不是自带全部素材的一键安装包，具体验证范围见版本记录。

## 界面使用流程

1. 用一句自然语言描述视觉任务，或选择一个预置演示技能。
2. 审核生成的语义意图和可编辑条件。
3. 仅在任务需要时补充区域、方向参考等场景资源。
4. 校验并生成当前可运行版本。
5. 在图片或视频上运行，查看证据和业务结果。

## 设计原则

- 生成的技能必须完整可见、可编辑。
- 视觉证据与业务判断必须分离。
- 每个算子必须具有明确版本、参数和输入输出类型。
- 媒体预处理、Grounding、跟踪、逻辑及时序行为必须在生效工作流中显式呈现。
- ROI 等场景资源只在任务语义确实需要时才作为运行条件。
- 旧技能默认保持兼容，除非执行明确的迁移。
