# ADR 0001: V3 单媒体运行边界

- 状态：Accepted
- 日期：2026-08-21

## 决策

V3 首期一次运行只消费一个图片或一个视频媒体源。同一媒体内允许动态数量的区域、方向、目标、业务分支和时间阶段；一个技能可声明图片与视频两个 variant，但单次运行只能确定性选择其中一个。

普通用户界面不开放 camera、scene、field 关联范围。跨媒体、多摄像头同步和跨镜身份必须由未来独立 MultiStreamRun 协议实现。

## 原因

单媒体边界让时间戳、资源坐标、身份、证据和重放语义保持确定，避免界面暗示尚不存在的多流能力。

## 验收

- 图片任务使用视频时序能力时确定性拒绝。
- 每次运行记录唯一 media_asset_id、媒体类型和 variant。
- 多区域数量不需要预设，运行时均绑定到同一媒体。
