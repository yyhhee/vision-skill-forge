## 已知未修复问题：存档不掩盖缺陷

以下是原前端审计已确认的问题，本次不修改业务代码，不因151项原有测试通过就认为问题消失：

1. **F01，高优先级：校验入口不一致。** 最终NOT有两个成员等非法组合可经过导入、应用。需要统一结构／引用／类型／逻辑基数／有限数值／媒体规则的校验入口。
2. **F02：图片时间约束不完整。** 图片即时判断可保存并应用“保持5秒”，面板还可能误写视频说明。应按媒体收敛有效期，保留非法导入值并明确阻断，而非静默清除。
3. **F03：运行摘要与实际参数不一致。** 计数改为3后，运行快照正确，摘要仍可能显示旧2。需要从对应快照统一生成摘要，区分用户名称和实际规则。
4. **历史规格工具过时。** `frontend/docs/design-spec/validate_spec.py --self-test` 当前返回JSON的 `result=failed`，原因是固定要求16条D决策，而DECISIONS已增至19条。原记录完整保留；此次不修改历史规格来伪造通过。该脚本本身可能以退出码0返回，须读结果字段。

完整背景见[此前新旧项目联动审核](../frontend/qa/integration-audit-2026-10-20/REVIEW.md)。这是一份历史审计，里面的旧项目HEAD、测试时间和路径不是本次新分支的实时状态。

## 怎么运行与恢复

先在新目录固定检出标签，不覆盖当前使用的任何目录：

```powershell
git clone --branch checkpoint-frontend-prototype-20261020 --single-branch https://github.com/yyhhee/vision-skill-forge.git vision-skill-forge-frontend-restore
cd vision-skill-forge-frontend-restore/frontend
npm ci
npm run dev -- --host 127.0.0.1 --port 6175 --strictPort
```

若6175已占用，应先确认进程归属，不停掉未知服务。前端本地素材和字体已在本标签中；不需要原版未入库的验收媒体、Python服务或真实模型来打开这个前端原型。

E2E验证应先确保6175未被手动预览占用，再执行：

```powershell
$env:VSF_TEST_BASE_URL = "http://127.0.0.1:6175"
$env:VSF_REQUIRE_OWN_SERVER = "1"
# 安装Playwright对应Chromium，或设置VSF_CHROMIUM_EXECUTABLE到已安装的独立Chromium。
npm run test:e2e
```

该命令会启动／结束自己的测试服务；不复用旧6174。截图命令要有正在运行的对应预览服务，不能与独占端口的测试启动混用。测试和截图不会迁移用户localStorage；相关数据备份属于另一个显式操作。
