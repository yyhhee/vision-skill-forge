### 安全恢复

不要覆盖正在运行的目录；先将标签克隆到一个不存在的新目录：

```powershell
git clone --branch checkpoint-original-20261020 --single-branch https://github.com/yyhhee/vision-skill-forge.git vision-skill-forge-restore-20261020
```

该命令固定检出标签，通常处于 detached HEAD；只有要继续修改时，才在恢复副本新建开发分支。

随后按 README 创建／选择环境，在本地配置模型连接，并从本地备份将 `imgs/` 与 `data/acceptance_media/` 恢复到副本的对应位置。部分历史素材 manifest 保存绝对路径，换机器后还需核对或重新生成，不能仅凭复制宣称跨机器通过。先选择未占用端口，确认原服务不受影响，再进行复验和切换决策。不要直接使用 `git reset --hard` 或强制推送来“还原”。

密钥、外部模型权重、未入库用户技能、运行记录及本地媒体需要另行备份和恢复；不要把秘密写入版本记录。
