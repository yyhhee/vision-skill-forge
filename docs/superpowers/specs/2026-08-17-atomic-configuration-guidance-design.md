# 原子能力配置引导设计

## 目标

在创建页和审核页用少量只读卡片解释现有 `SkillPackage` 已编译出的原子能力，帮助用户知道哪些参数可修改、是否需要媒体或场景标注。卡片不新增运行时算子、不复制一套专用拥堵/逆行配置系统。

## 方案

从当前 variant 的 DAG、事件节点、告警节点和配置槽推导展示模型：类别过滤、统计范围、数值比较、AND/OR/NOT、持续时间、触发方式、告警名称，以及区域/方向箭头配置槽。方向规则没有数值比较时显示“方向/空间关系”，明确需要命名区域和参考箭头，避免显示空的比较条件。

创建页在生成/加载状态后显示一张 Markdown 引导卡；自然语言、预置、已保存和资产加载统一刷新它。审核页继续使用现有编辑控件，只补充方向规则的可读说明。用户仍通过现有审核和标注页修改，不增加跨页按钮或专用算子。

## 验收

- P04 卡片说明车辆、命名区域、数量/速度阈值、AND、持续时间、告警和去标注页绘制区域。
- P05 卡片说明车辆、方向/车道关系、参考箭头、持续时间和告警，并明确不是数量/速度比较。
- 无事件的技能显示无需事件配置；无场景槽的技能显示无需场景标注。
- 全量现有测试保持通过。
