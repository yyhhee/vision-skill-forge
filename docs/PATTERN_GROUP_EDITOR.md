# 编排组编辑：选组即改、步骤移动、依赖可见

## 入口与操作

**03 审核 → 事件规则编辑 → 分支编排**。

1. 在「选择要编辑的编排组」选择已有组，立即回填该组名称、基础关系、成员、时间窗口和关联范围。选择「新建编排组」才创建另一个组。
2. 在成员框增加或移除输入；成员可以是条件分支，也可以是已有编排组。相同名称按编号区分，不暴露内部 ID。
3. 在「要移动的步骤」选中一步，点击「上移一步／下移一步」。预览与步骤编号同步更新，移动后仍选中同一输入；到首尾不会越界。
4. 依赖区分别显示「本组使用的输入（本次设置）」和「谁在使用本组（当前草稿）」；包括直接引用它的组、最终判定和业务输出。这里的输入依赖不等于运行先后；只有顺序关系要求按步骤发生。
5. 点击「保存编排组到草稿」，再点击「应用修改，更新运行版本」。移动步骤或改表单不会直接发布，也不会改写其他组。

组、关系、步骤选择器直接展示完整选项，不需要先删除当前名称才能切换。

## 保存与引用安全

- 编辑使用明确 `pattern_id`，不再凭成员相同推断待编辑组。
- 新建显式传递 `create_new=True`，相同成员也不会覆盖已有组。
- 更新保留组 ID、未变化输入的阶段 ID、实例策略和触发策略；按原位置替换组，不改变组列表顺序。父组、最终判定、业务输出的引用继续有效。
- 新增阶段避开已有阶段 ID；顺序关系按新步骤顺序重建相邻边。
- 输入选择排除当前组及依赖当前组的组；后端继续拒绝循环引用、失效引用，以及未解除依赖的取消操作。
- 新建保存一次性返回完整选项列表和选中值，避免 Gradio 后续回调因新 ID 尚未出现在选项中而失败。
- 「相邻步骤最长间隔」允许空值或 0，均表示不限制；需要观察窗口的关系仍要求大于 0 秒。非窗口关系忽略隐藏的窗口旧值。
- 含步骤独立计时、逐段不同间隔、自定义锚点、额外汇聚关系等高级约束的组，在普通表单提示只读并禁止保存，继续使用高级入口，不把复杂关系扁平化。

## 实现

- `ui/v2/controllers/pattern_editor.py`：选择、预览、移动、依赖说明、受控保存。
- `ui/v2/bindings/pattern_editor.py`：组选择与移动回调；保存沿用统一草稿事务。
- `core/business_rule_editor.py`：新增显式创建选项，稳定阶段与组身份，原位更新。
- 原 `business_secondary_controls` API 保留；界面通过适配器刷新输出、最终判定与触发策略，不再覆盖用户当前选中的组。
- 不引入新 DSL、执行算子或场景专用规则；不修改预置文件或模型提示词。
