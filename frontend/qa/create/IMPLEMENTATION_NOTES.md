# 02 一句话创建：纯前端实施边界

入口 `/skills/new`；固定对比入口 `/skills/new?fixture=02`。新建按钮由01进入02；“演示示例与高级选项”保留从完整模板新建，仍使用原库页事务。没有新建另一套编辑器、版本格式或配置存储。

## 最小组件划分

- `src/data/creation.ts`：精确演示查表、输入验证、完整预览、清空区域几何、通过原仓库事务持久化。不是NL解析器、LLM调用或规则Repair。
- `src/components/create/SkillCreate.tsx`：表单、绑定输入签名的预览、保存/继续、未保存导航和历史保护。名称/描述/媒体变化都让旧预览失效。保存成功后锁定创建表单，避免另存重复技能；后续变更在现有编辑器进行。
- `src/components/create/CreationPreview.tsx`：只读理解图，节点文字取自同一份预览文档，原生React Flow依赖线与现有Phosphor图标。图中两个独立目标分支汇入最终AND，再引用业务输出。
- `src/styles/creation.css`：仅创建页局部样式。没有增加依赖、全局设计系统、服务器或新的模型路由。

## 保存与生效

`显式选择示例 → 预览 → 新身份 + 完整SkillDocument + R0 + V1 → 03绘制区域 → 编排编辑 → 校验应用R1`。

没有从语言推断坐标；区域资源的points为空且saved=false。没有继承原演示R3，没有自动应用，没有自动运行。保存写入失败则留在当前页，保留输入和预览。原始种子、已有草稿和历史运行不变。所有fixture模式均禁止写入正常数据。

仅明确列出的原句可以生成固定演示预览；安全帽、沙发、其它区域阈值、语义改写等未知描述必须明确报“未连接LLM”。完整模板是另一项明确的复制操作，不冒充语言理解。未来接入真实LLM可替换预览提供者，但本轮未设计/接入后端协议。
