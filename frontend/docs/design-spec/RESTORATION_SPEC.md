# 前端还原实施规格 v1

## 1. 目标与取舍

交付独立纯前端交互版本：视觉忠实还原选定的 16 张图；控件和跨页主流程真实可操作；模型生成、识别与运行结果明确使用模拟数据。
本轮只制定规格，不搭建工程。后续不复用 Gradio DOM，不把整张效果图铺作背景，不用热区按钮伪装已实现。

基准优先级：
1. 用户明确约束；
2. DECISIONS.md 中已登记修正；
3. 04 作为公共视觉基准；
4. 各页原图的布局／状态；
5. 未覆盖处复用公共组件，不能新增另一套主题。

16 张是同一应用的页面与关键状态，不是 16 个互不相关的静态页面。通用组件要复用，但不能为了复用强行让不同页面布局相同。

### 2.3 固定的设计语言

- 全站浅色：背景#F6F8FC、工作区白、画布#F8FAFC。
- 主操作/选中靛蓝#4F46E5；橙和青只标识区域与分支，不承担唯一选中或成功含义。
- 字体选择Noto Sans SC，正文16/24；元信息14/20；标题24/32；使用400/500/600/700真实字重，不伪加粗。
- 原生成图的精确字库未知。选定字体后须本地归档、记录散列、等待加载完成再截图。家族名称锁定不代表字体文件已交付。
- 图标选Phosphor同一家族，导航/工具用regular，业务语义用duotone；禁止系统emoji、混杂图标和手绘SVG替代。
- 主操作44px高、常规输入40px、紧凑画布控件36px、圆角8px。主区标题和表格密度以原图校准。
- 所有标签、输入、图标均为可访问的真实UI；媒体文字与编辑区域分层，不截图化整个表单。
- 每页一个明确主操作。全局页面不携带技能的运行/应用按钮。
- 参数通过同一右侧抽屉编辑；桌面宽度416px，覆盖局部工作区，不重新挤压底图比例。此项是D-03明确修正，不得按原图未修正区域套像素通过率。

### 2.4 响应式

原图视口是严格还原基准；另测1366×768和1920×1080。屏幕变窄先让参数区独立滚动，再允许预览/画布切为单视图；禁止全页面CSS scale缩小。
低于1100px默认单视图加切换，抽屉宽min(416px,100vw)。移动端只要求主要控件可达、不遮挡，不声称已有移动高保真参考。
浏览器缩放200%检查焦点与主要操作可达；不把这组测试与1:1原图截图混淆。

## 4. 前端组件边界

- AppShell：顶栏、上下文操作、侧栏、版本状态；操作配置由页面提供。
- SkillLibrary / SkillCreate / VersionPanel：列表、创建与完整归档。
- SkillWorkspace：SceneViewport、RuleCanvas、InspectorDrawer。
- SceneViewport：素材加载/等比显示、区域/方向/框、选择联动、媒体控件；覆盖层与照片分离。
- RuleCanvas：业务分支、条件组、事件组、最终判定、输出；拖动与连线；不直接暴露执行端口和算子ID。
- InspectorDrawer：条件、时间、编排组、输出、问题修正共用容器，表单按类型替换。
- ValidationSetup / RunMonitor / ResultExplorer：运行配置、模拟任务与证据联动。
- ModelSettings / CapabilityManager：只维护演示配置和清单，不实际执行插件。
- MockRepository：唯一模拟读写边界；UI不直接调用生产API。

建议工具沿用React+TypeScript+Vite、React Flow定制业务节点、react-konva标注层。不在本规格阶段安装依赖或捏造版本；建工程时锁定具体版本和lockfile。
结构保持单应用：页面、组件、数据仓库、fixtures和测试即可，不引入微前端、插件市场、权限服务或通用工作流后端。

## 5. 文档和版本状态

分清三层：
1. 表单未保存：还未进入文档；
2. 草稿已保存、未应用：文档已变，运行快照不变；
3. 已应用R_n：不可变本地运行快照；模拟运行只读取此快照。

保存归档V_n是完整文档副本，和运行修订R_n不是同一编号。草稿不显示成“R3草稿”。
保存/导出须包含：条件树、分支、嵌套编排组、时间与有效期、最终判定、输出/触发、场景标注、运行设置、素材引用与schema版本。
结果保留当次快照，编辑当前草稿不能反向改变旧事件或旧结果标签。

抽屉关闭、切换条件、切换技能/版本、离开页面时，存在未保存表单则提示保存／放弃／继续编辑。只改变画布平移或缩放不造成业务草稿变脏。
导入校验结构与引用；失败保留当前文档，不以默认值覆盖。区域/条件/编排组删除前检查依赖；不能静默删除下游。

## 6. 交互约束

### 6.1 画布

支持拖动、平移、缩放、适配视口、选择、编辑、命名、撤销/重做。循环、自引用、类型不兼容连线须阻止并解释。
AND/OR/NOT/至少N项是显式条件树；普通依赖线不表示顺序。顺序须显示箭头类型、锚点与时间间隔。
组复用必须保留稳定身份；修改组后所有引用更新，复制组才生成新身份。前端只校验结构与表单，不新建推理内核。

### 6.2 场景

矩形/多边形/方向可绘制、调整、命名、删除；像素映射须考虑object-fit、黑边、缩放和平移。
仅在绘制完并保存后将资源标记完成；已有几何但尚未保存不能误当满足运行条件。
同一选区与对应分支双向定位；目标结果框不是标注资源，不能混成同一类可编辑多边形。

### 6.3 条件

作用来源和实体身份明确；A颜色测量与B模型属性语义证据可AND/OR/仅A/仅B，B不得归给另一个主体。
示例是演示数据，不对图片真的测色或调用视觉模型。新增能力必须从本地演示目录选择，不能把任意名称当成已具备执行语义。
逻辑成员不限A/B，可新增C/D或嵌套组。不同成员来源不兼容时需提示而非自动换目标。

### 6.4 时间和关系

先选某条件或整个分支，再选具体来源；continuous只显示时长/允许中断，cumulative显示窗口/累计时长，ratio显示窗口/比例；repeat另显示次数/窗口。
禁止将“满足指定次数”当作同一continuous模式的隐式别名。切换模式保留草稿输入但仅提交适用字段。
关联按目标、轨迹、目标对、区域或整体；选择项根据来源类型收敛，没有轨迹来源不能选同一轨迹。
同一对象/区域需选择具体来源或集合，并说明逐实例/逐区域处理，不等于只允许选一个目标。
顺序关系说明前段取start/qualified/end、后段何时开始计时；不允许仅写“最长10秒”而隐去锚点。
不得为本效果图场景新增穿戴或人体特殊规则。

### 6.5 输出与触发

选择受控来源和兼容类型，不要求用户输入ID。删除或改变来源后标记待修正，不能悄悄选择其它来源。
布尔满足、目标列表、事件列表和阶段时间线是不同结果，不能将成功执行当成业务成立。
外部通知未接入时显示未接入，不模拟为真实已发送。

## 7. 无后端时的行为

生成仅支持明确列出的演示输入；其它自然语言提示未接入编排模型，不能返回固定规则冒充通用编排。
运行是固定脚本演示，展示状态切换和数据联动；不是模拟检测器、测色器或时序推理算法。修改规则后旧演示结果标记不匹配，不能继续显示为新规则的证明。
06/07等固定用例的文档意图为video_demo，预览交付暂为poster_only；允许演示视频时间配置，但不得声称有真实视频播放/时序结果。普通用户明确选择图片模式时，视频顺序等选项仍须禁用。预览载体不等于声明了真实视频文件。
模型“测试连接”显示模拟测试；禁止向用户填的地址发请求。仅保存非敏感配置，凭证不持久化、不导出。
安装仅演示schema化能力清单导入和依赖检查；不加载JS/Python、安装包或执行用户脚本。
可以本地导入/导出JSON，和以版本化key保存演示配置；媒体用用户文件/可释放ObjectURL，不能把大视频放localStorage。
截图测试每例独立种子，不能依赖前一例保存后的状态。
