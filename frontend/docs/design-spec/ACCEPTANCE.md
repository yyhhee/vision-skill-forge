# 还原与交互验收标准

## 0. 两套独立结论

- 视觉：与选定参考图及D-ID修正规则相符。
- 功能：前端操作与数据流按规格工作。
构建、类型检查、HTTP200、打开浏览器、单张截图都不能代替上述任一结论。本规格包自检也不是软件验收。
最终交付必须所有页面无未关闭P0/P1/P2，两个结论分别有证据；不能用80%平均分掩盖某页不可用。

## 1. 截图环境冻结

记录：操作系统、真实浏览器产品/版本/内核、CSS视口、DPR、浏览器缩放、字体文件散列、主题、locale、时区、固定时钟、fixture、素材散列。
按每张原图真实1512/1513×1039/1040像素设置对应CSS视口，DPR=1，100%zoom。捕获应用内容，排除浏览器/桌面外框，不整页滚动拼接。
视觉fixture时钟冻结2026-10-17 10:26 Asia/Shanghai，以匹配图16“今天”；规格编写日期为2026-10-19。普通演示模式不把旧日期谎称今天。
等待document.fonts.ready、图片解码和画布布局稳定；游标离开控件、不hover、滚动归零、选中态/抽屉/折叠项匹配；关闭动画、随机数与自动播放。
模拟进度停在18/30，不依赖真实setTimeout“刚好截到”；React Flow viewport使用固定fit/zoom/pan而非窗口自适应随机结果。
浏览器捕获使用用户可用且选定的浏览器；工具不可用应记录blocked，不擅自切到其它已登录浏览器或把截图任务转成仅HTTP测试。

## 2. 每页必须保存的证据

路径建议 qa/<caseId>/<iteration>/：
- reference-original.png（已锁原图/引用及SHA）；
- implementation.png（原始浏览器截图，禁止后期修补）；
- side-by-side.png（等尺寸并排）；
- overlay-50.png（同原点原比例，参考/实现各50%）；
- diff.png（差异高亮，不是把差异涂平）；
- metrics.json（尺寸、定位点、对比参数、原始/修正后差异分别记录）；
- interactions.json或测试记录；
- console.txt及network记录；
- review.md（结论、问题、D-ID和下一轮修复）。

叠加/差异图是确定性对比产物，不使用生成式模型重绘“正确截图”。原图和真实截图永不覆盖；不得为了相似先缩放、扭曲、裁切掉有问题的区域。
必须把参考与实现放在同一张比较输入里再评价；只分别看过两张图不算完成对比。

## 3. 两层视觉基准

### A. 首次原图还原
逐页与原图叠加，固定同视口/数据/展开态，检查五项：字体、间距布局、颜色、素材、文字。
生成图有抗锯齿/纹理噪声和未知字库，不虚构“像素相似99%”。差异比例只能辅助定位，不能单独当通过指标。
D-ID范围内须逐项解释并显示修改后结果；D-ID不允许把整个页面mask掉。
对未改区域要求：主布局锚点偏移≤2px，次级间距≤2px，无换行/表格行高/可见内容密度的明显变化；字体大小/行高/字重匹配选定规范，缺字或fallback阻断。
若这些目标与已批准布局修正冲突，单独标注该修正位置，不能对其它区域放宽。

### B. 修正后的回归基准
仅在A完成且无P0/P1/P2、每个修正有人工复核记录后，登记normalized基准。该图由真实渲染生成，但必须带原图比对与D-ID，禁止自己截自己直接认定passed。
后续同环境回归可设置per-channel容差12/255、变化像素占比≤0.5%作为报警起点；需在首次稳定截图后校准并锁定参数。不是已测出的当前成绩。
整页及重点区域分别检查；一张大照片不能稀释按钮/字体差异。不允许只mask照片后声称整页1:1。
冻结媒体帧、字体、光标和动画；仍有动态区需精确登记矩形、原因、单独检查方法，不能临时扩大mask。

## 6. 严重度与门禁

P0：主路径不可用、数据丢失、凭证泄漏、误把模拟当真实。
P1：主布局/素材严重不符、错主体或错版本、核心操作失败。
P2：字段不可达、明显换行/比例/状态冲突、恢复入口缺失、响应式遮挡。
P3：无实质影响的抗锯齿/轻微图标光学差异，需逐项列明不能打包忽略。

- 设计规格/引用自检通过：仅表示资料可用。
- 构建/类型/单元检查通过：仅表示代码检查通过。
- 浏览器功能检查通过：需F用例记录及控制台检查。
- 视觉通过：必须有原图+真实截图+叠加/差异+重点局部复核。
- final result只可写passed或blocked；缺图、缺比较、缺素材、缺操作证据均blocked，不得写“基本完成”代替。

## 7. 迭代与交付

发现P0/P1/P2 → 记录位置/证据/修正 → 改代码 → 同状态重新截图 → 再对比，不能沿用旧截图。
报告保留每轮发现、对应修复与复验图片；不以反复更新基准来消除差异。
交付需16例状态清单、逐页结论、功能记录、资产清单、未解决P3、可打开预览与源码。若只有规格，本轮只能报告“规格完成”。
