# 运行记录：数据与交互约定

入口`/runs`，纯前端模拟运行归档，不是后端任务列表。直接复用`vsf-frontend-run-v1`，本页没有新的持久化数据键、写入、删除、执行、自动重启或导入功能。

## 来源

- 正常模式只读既有`{schemaVersion:1,runs:DemoRun[]}`；没有归档就是空列表，不写空缓存或演示记录。
- 检查每个运行的既有结构、快照、状态、采样点、事件/证据约束和唯一身份；缓存损坏、不兼容、空字符串或身份重复时失败关闭，保留原文。
- `fixture=run-history`只读隔离示例：规范的五条摘要，其中区域R3使用已有完整`exampleRun(true)`。其余仅有摘要，不能使用同一份区域告警详情冒充。
- 当前草稿和保存V不决定历史名称/版本/结果；历史来自当次不可变snapshot。源技能删除、停用能力不破坏历史查看。
- 普通历史链接缺失时显示未找到，即使ID恰好等于内置示例ID也不重建示例；示例只在明确隔离fixture中展示。

## 筛选和选择

搜索、状态、媒体、技能范围、日期取交集。开始时间按北京时间显示/筛选；自定义日期包含结束当天，拒绝非法/逆序日期。最近7天包含今天；fixture时钟固定2026-10-17，正常模式使用真实当前日期。

按开始时间倒序，每页5项；分页数量来自实际匹配数。列表选择用于预览，勾选用于查看/批量导出；查看所选结果只允许一条。页头选择框只选择当前页，跨页勾选可导出；改变筛选清空勾选，不能误看隐藏的其它任务。过滤后的详情不能显示已不匹配的行。

地址栏保存`q/status/media/skill/range/from/to/page/selected`导航状态，并保留已有history索引；不会把搜索/选择写入运行快照。从结果浏览器返回时恢复该上下文。库中“查看运行记录”打开对应技能过滤列表，空也不借用其它技能结果。

## 打开与导出

打开/导出时重新读归档确认身份。完成记录进入现有结果页；未结束、取消、失败进入对应已有进度/状态页。未结束任务默认暂停，继续要用户显式操作；离开列表不创建新任务。

未知素材没有缩略图，不跳到施工海报查看器；仍可导出真实完整记录。只有参考摘要的条目弹说明，导出明确标记`vsf-run-summary`、`snapshotIncluded:false`、`detailsAvailable:false`。完整运行直接导出其原始结构的克隆；批量包`vsf-run-records.records`逐一保留完整运行或带标记摘要，不拼成假的统一事件。

结果未提供/尚未完成时计数显示“未提供”，不是0个检测目标。没有真实视频和证据文件，不提供标注视频/证据包下载。损坏缓存可显式导出`vsf-raw-run-cache`备份原文，然后重新读取；本页不会清空缓存来“修复”错误。

跨标签storage和窗口focus会重新读列表，不写回旧副本。现有创建/编辑/版本/模型/能力导入/运行设置离开守卫继续使用，保存后继续必须携带刚保存的文档，而非旧闭包。

## 组件边界

- `src/data/runHistory.ts`：只读适配、隔离摘要、日期/筛选、导出类型。
- `src/components/history/RunHistory.tsx`：页面状态、路由上下文、筛选/分页/选择、确认实际记录后导航。
- `src/components/history/RunHistoryDetail.tsx`：受控详情展示，不读写归档或运行模型。
- `src/styles/history.css`：页面专用样式，不更换全局主题/字体/素材。

不引入任务队列、自动模型路由、自动执行、云存储或插件代码。原6131成品版本保持不变。
